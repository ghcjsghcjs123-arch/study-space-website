# 공부 유형별 공간 설계 웹사이트 – 코드 초안

## 실행 방법
폴더 안의 `index.html`을 더블클릭하면 브라우저에서 바로 열려요. 설치할 것은 없어요.

## 들어 있는 기능
1. **질문 화면**: "What am I studying today?"와 공부 유형 버튼 4개
2. **디자인 카드**: 3D 방(또는 평면도), 공간 요소 3개(Lighting, Noise, Seating)와 각각의 이유·근거 연구
3. **3D 보기** (지금은 Idea Lounge만): 카드에 3D 방이 바로 보여요. 다른 공간은 아직 2D 평면도만 보여요.
   - 마우스로 끌면 방이 돌아가고, 휠이나 두 손가락으로 확대·축소해요. 키보드 화살표와 +/-도 돼요.
   - "Floor plan" 버튼으로 2D 평면도를 볼 수 있어요.
   - "Full screen"을 누르면 화면 전체에 열려요. ×나 Esc로 닫고, 닫으면 소리도 멈춰요.
   - **Light 버튼**: 우리 디자인 조명(어둑하고 따뜻한 빛) ↔ 비교 조명(밝은 사무실 빛)
   - **Ceiling 버튼**: 우리 디자인 천장 3.2 m ↔ 비교 천장 2.4 m (벽이 실제로 올라가고 내려가요)
   - 버튼을 누르면 아래에 그 비교를 설명하는 문장과 근거 연구가 나와요.
4. **조명 미리보기**: 공간을 고르면 페이지 전체가 그 공간의 조명 색으로 바뀌어요. 바뀔 때 전등이 켜지듯 깜빡이고, 버튼으로 켜고 끌 수 있어요.
5. **소리 체험**: "Hear this space"를 누르면 공간의 소리가 재생돼요. 소리는 모두 브라우저가 직접 만들어서 음원 파일이 없고, 저작권 걱정도 없어요. Esc 키를 누르면 소리가 꺼져요.
   - Focus Room: 조용한 방
   - Idea Lounge: 카페 소음(웅성거림과 컵 소리)
   - Team Studio: 토론하는 소리
   - Green Nook: 바람과 새소리
6. **비교 화면**: 디자인 4개를 나란히 비교
7. **설문 결과 자리**와 **근거 연구 목록**

## 파일별 역할 (고칠 때 어디를 보면 되나)
| 파일 | 내용 | 이런 걸 고칠 때 |
|---|---|---|
| `data.js` | 카드 문구, 이유, 연구 링크, 3D 비교 문장(`view3d`) | 문장이나 근거를 바꿀 때 (가장 자주 고침) |
| `style.css` | 디자인, 공간별 조명 색 | 색이나 분위기를 바꿀 때 |
| `plans.js` | 평면도 그림 | 배치도를 바꾸거나 손그림으로 교체할 때 |
| `space3d.js` | 3D 방 (CSS 3D만 사용, 라이브러리 없음) | 3D 방을 고치거나 새 방을 추가할 때 |
| `sound.js` | 소리 만들기 | 소리 크기나 종류를 바꿀 때 |
| `app.js` | 화면 동작 | 기능을 추가할 때 |
| `CLAUDE.md` | Claude Code용 프로젝트 설명 | 용어 규칙이 바뀔 때 |

## 3D 방 추가하는 법 (예: Focus Room)
1. `data.js`의 그 디자인에 `view3d`를 추가해요. Idea Lounge 것을 복사해서 천장 높이, 조명 프리셋, 비교 문장을 바꾸면 돼요.
2. `space3d.js`의 `BUILDERS`에 `memorization(k) { ... }` 함수를 추가해요.
   - `k.room({ w: 8, d: 6 })`로 바닥과 벽(뒷벽, 왼쪽 벽)을 만들고, `k.add(...)`로 가구를 넣어요.
   - 모든 크기는 미터 단위예요(1 m = 46 px). x, y는 물건 바닥의 **가운데**, z는 **바닥에서의 높이**예요. 뒷벽은 y = 0, 왼쪽 벽은 x = 0이에요.
   - 도우미 함수: `box`(가구 상자), `plane`(바닥·벽·칠판), `crossed`(화분 잎·전등 빛), `group`(여러 부품 묶기·회전), `label`(이름표)
   - 이미 있는 가구: `loungeChair`, `roundTable`, `pendant`, `floorLamp`, `plant`, `pool`(바닥 빛 번짐)
   - 새 조명 색이 필요하면 `LIGHTS`에 프리셋을 추가해요.
3. 그러면 카드에 3D 보기가 자동으로 생겨요.

## 참고
- 소리 크기는 실제 데시벨이 아니라 '느낌'을 보여주는 정도예요. 발표 때 "~70dB 느낌"이라고 말하는 게 정확해요.
- 인터넷이 없으면 글꼴만 기본 글꼴로 바뀌고, 나머지 기능(3D 포함)은 그대로 작동해요.
- 3D 화면 안에서는 손가락으로 끌면 방이 돌아가요. 휴대폰에서 페이지를 스크롤할 때는 3D 화면 바깥을 끌어 주세요.
