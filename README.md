# 공부 유형별 공간 설계 웹사이트 – 코드 초안

## 실행 방법
폴더 안의 `index.html`을 더블클릭하면 브라우저에서 바로 열려요. 설치할 것은 없어요.

## 들어 있는 기능
1. **챗봇 화면**: 질문 두 개(공부 유형, 기분)에 답하면 우리가 디자인한 공간 중 맞는 곳을 보여 줘요
2. **디자인 카드**: 3D 방(또는 평면도), 공간 요소 3개(Lighting, Noise, Seating)와 각각의 이유·근거 연구
3. **3D 보기** (4개 공간 모두): 카드를 열면 3D 방이 바로 보여요.
   - 마우스로 끌면 방이 돌아가고, 휠이나 두 손가락으로 확대·축소해요. 키보드 화살표와 +/-도 돼요.
   - "Floor plan" 버튼으로 2D 평면도를 볼 수 있어요.
   - "Full screen"을 누르면 화면 전체에 열려요. ×나 Esc로 닫고, 닫으면 소리도 멈춰요.
   - **Light 버튼**과 **Ceiling 버튼**으로 우리 디자인과 비교 디자인을 바꿔 볼 수 있어요. 천장을 바꾸면 벽이 실제로 올라가고 내려가요.
   - 버튼을 누르면 아래에 그 비교를 설명하는 문장과 근거 연구가 나와요.

   | 공간 | 조명 (우리 디자인 ↔ 비교) | 천장 (우리 디자인 ↔ 비교) | 3D 방 안의 것 |
   |---|---|---|---|
   | Focus Room | 밝고 균일한 흰빛 ↔ 어둑한 주황빛 | 2.4 m ↔ 3.2 m | 칸막이 1인 책상 8개, 의자, 스탠드, 시계, 창문, 책장 |
   | Idea Lounge | 어둑하고 따뜻한 빛 ↔ 밝은 사무실 빛 | 3.2 m ↔ 2.4 m | 라운지 의자 3개, 커피 테이블, Idea wall, 걷는 동선 |
   | Team Studio | 밝고 따뜻한 빛 ↔ 어둑한 빛 | 3.0 m ↔ 2.4 m | 둥근 테이블 3개와 의자 15개, 공유 화면, 바퀴 달린 화이트보드 |
   | Green Nook | 자연광(연두빛) ↔ 차가운 흰빛 | 3.0 m ↔ 2.4 m | 벽 전체 창문(나무 풍경), 소파, 빈백 3개, 화분 여러 개 |
4. **조명 비교**: 3D 창 안의 Light 토글로 조명을 바꿔 볼 수 있어요. 페이지 배경은 항상 흰색이고, 조명은 3D 창 안에서만 바뀌어요.
5. **소리 체험**: "Hear this space"를 누르면 공간의 소리가 재생돼요. 소리는 모두 브라우저가 직접 만들어서 음원 파일이 없고, 저작권 걱정도 없어요. Esc 키를 누르면 소리가 꺼져요.
   - Focus Room: 조용한 방
   - Idea Lounge: 카페 소음(웅성거림과 컵 소리)
   - Team Studio: 토론하는 소리
   - Green Nook: 바람과 새소리
6. **비교 화면**: 디자인 4개를 나란히 비교
7. **설문 결과 자리**와 **근거 연구 목록**

## 첫 화면: 공간 찾기 챗봇
첫 화면에서는 챗봇이 질문 두 개를 하고, **우리 팀이 디자인한 네 공간 중 지금 나에게 맞는 공간**을 보여 줘요. 실제 아주대 공간을 골라 주는 게 아니에요.

1. 질문 1: "오늘은 어떤 공부를 하나요?" → 암기 / 아이디어 구상 / 팀플 / 편안함
2. 질문 2: "지금 기분은 어때요?" → 집중 / 막막함 / 활기참 / 피곤함
3. 결과 말풍선에서 **"○○ 보기"** 버튼을 누르면 그 공간의 디자인 카드가 열려요. 메인 공간 버튼은 진하게, 함께 보면 좋은 공간 버튼은 연하게 보여요.
4. 결과 아래에 **처음부터 다시**와 **네 가지 디자인 모두 보기**가 있어요.

결과를 정하는 규칙이에요. 기분마다 연결된 공간이 있어요. 집중은 Focus Room, 막막함은 Idea Lounge, 활기참은 Team Studio, 피곤함은 Green Nook이에요.

| 규칙 | 언제 | 메인 공간 | 함께 보여 주는 공간 | 문장 |
|---|---|---|---|---|
| A | 기분의 공간 = 공부 유형의 공간 | 그 공간 | 없음 | 메인 문장 + "지금 기분과도 딱 맞아요" |
| B | 피곤함 (공부 유형이 편안함이 아닐 때) | Green Nook | 공부 유형의 공간 | "피곤하다면 쉬는 게 먼저예요…" |
| C | 그 밖의 경우 | 공부 유형의 공간 | 기분의 공간 | 메인 문장 + 기분 팁 |

- **문장 고치기:** 챗봇 문장은 `data.js`의 `CHAT`, 기분 목록은 `MOODS`에 있어요. 인사·질문·버튼 글자는 `i18n.js`에 있어요. 영어와 한국어를 둘 다 고쳐 주세요.
- **영어 표현:** 영어 문장에는 "recommend" 대신 "fits"를 써요(교수님 피드백).
- **대화 유지:** 대화 중에 KO | EN을 바꾸거나, 결과에서 카드로 갔다가 뒤로 와도 대화가 그대로 남아요. 처음부터 다시 하려면 "처음부터 다시"를 누르거나 새로고침하면 돼요.

## 디자인 규칙 (새 화면을 만들 때도 지켜 주세요)
- 흰 배경에 검정 글자를 쓰고, 강조색도 검정 하나예요. 공간별 색(파랑, 주황, 초록)은 3D 모델 안에만 써요.
- 글꼴은 Pretendard 하나예요. 위계는 글자 크기와 굵기로만 줘요. 세리프 글꼴, 넓은 자간의 대문자 라벨, 배지는 쓰지 않아요.
- 상자 테두리, 그림자, 그라데이션, 알약 모양 버튼은 쓰지 않아요. 구역은 여백과 1px 회색 선으로만 나눠요.
- 버튼은 두 종류예요. **검정 주 버튼**과 **밑줄 글자 버튼**이에요. 켜고 끄는 선택(3D 보기/평면도, 조명, 천장)은 회색 바탕의 세그먼트 컨트롤이에요.
- 모서리는 버튼 6px, 3D 창과 이미지 8px, 나머지는 0이에요. 챗봇 말풍선만 예외로 12px예요.
- 여백은 8px 단위(8, 16, 24, 32, 48, 64, 96)로 맞춰요. 본문 최대 너비는 1080px, 긴 글은 720px이에요.
- 자세한 값은 `style.css` 맨 위의 변수와 `CLAUDE.md`의 Style 항목에 있어요.

## 화면 구성과 뒤로 가기
한 번에 한 화면만 보여요. 화면마다 주소 끝(#)이 달라요.

| 화면 | 주소 | 상단 버튼 |
|---|---|---|
| 챗봇 (첫 화면) | `#/` | 내 공간 찾기 / Find your space |
| 네 가지 디자인 비교 | `#/compare` | 비교 / Compare |
| 설문 결과 | `#/survey` | 설문 / Survey |
| 근거 연구 (논문별 카드) | `#/research` | 연구 / Research |
| 디자인 카드 | `#/idea` 등 | (내 공간 찾기로 표시) |
| 전체 화면 3D | `#/idea/3d` 등 | (내 공간 찾기로 표시) |

- 상단 버튼 중 지금 보고 있는 화면이 진하게 표시돼요. 휴대폰에서는 버튼이 한 줄로 보여요.
- 브라우저나 휴대폰의 뒤로 가기를 누르면 바로 전 화면으로 돌아가요.
- 디자인 카드와 전체 화면 3D의 **← 뒤로** 버튼도 온 곳으로 돌아가요. 예를 들어 비교에서 왔으면 비교로, 챗봇에서 왔으면 챗봇으로 가요.
- 화면이 바뀌면 맨 위로 올라가고, 소리는 멈춰요.
- 챗봇 대화는 다른 화면에 다녀와도 그대로 남아요("처음부터 다시"를 누르면 초기화).
- 주소를 그대로 공유할 수 있어요. 예: `.../index.html#/teamwork/3d`, `.../index.html#/research`

## 연구 화면
- 논문 11편마다 카드가 있어요. 순서는 10주차 문헌조사와 같아요.
  - 전체 근거: Barrett
  - 집중: Meyers-Levy, Mehta & Zhu 2009
  - 창의: Mehta·Zhu·Cheema, Steidle, Oppezzo
  - 협업: Brooks
  - 휴식: Kaplan, Berman, Lee, Atchley
- 카드에는 저자·연도, 학술지, 설명(4~5문장), **적용한 공간** 버튼, **원문 보기** 링크가 들어가요.
- 설명 문장은 `data.js`의 `STUDY`마다 `about: { en: [...], ko: [...] }`로 들어 있어요.
- "적용한 공간"은 디자인 카드에서 그 논문을 근거로 쓴 공간이 자동으로 표시돼요. 근거로 쓴 공간이 없으면 이 칸은 숨겨져요.

## 한국어 / 영어 전환
- 상단 바 오른쪽의 **KO | EN**으로 언어를 바꿔요. 기본은 영어예요.
- 고른 언어는 브라우저에 저장돼서 새로고침해도 유지돼요. 저장이 막힌 환경에서는 영어로 열려요.
- 문구를 고칠 때는 **영어(en)와 한국어(ko)를 둘 다** 고쳐 주세요. 예: `tagline: { en: "...", ko: "..." }`
- 용어: Memorization=암기, Idea generation=아이디어 구상, Teamwork=팀플, Comfort=편안함
- 공간 이름(Focus Room, Idea Lounge, Team Studio, Green Nook), 연구 이름(저자, 연도), 링크는 번역하지 않아요.
- 글꼴은 한국어와 영어 모두 Pretendard예요. 인터넷이 없으면 컴퓨터 기본 글꼴로 보여요.

## 3D 방 고치는 법
- **문장, 버튼 글자, 천장 높이**: `data.js`의 각 디자인 안 `view3d`에서 고쳐요. 공간마다 따로 있어요.
  - 설명 문장은 `{ text: { en: "Sentence.", ko: "문장." }, source: "저자, 연도" }` 모양이에요. 화면에는 "문장 (저자, 연도)."로 나와요.
  - 근거 연구가 없는 문장은 `source`를 빼면 돼요. 근거는 data.js에 이미 있는 연구만 써요.
- **가구 위치나 모양**: `space3d.js`의 `BUILDERS` 안에서 그 공간의 함수를 고쳐요. 공간 id는 memorization, idea, teamwork, comfort예요.
  - 새 공간을 만들 때는 `k.room({ w: 10, d: 8 })`로 바닥과 벽(뒷벽, 왼쪽 벽)을 만들고, `k.add(...)`로 가구를 넣어요.
   - `k.room({ w: 8, d: 6 })`로 바닥과 벽(뒷벽, 왼쪽 벽)을 만들고, `k.add(...)`로 가구를 넣어요.
   - 모든 크기는 미터 단위예요(1 m = 46 px). x, y는 물건 바닥의 **가운데**, z는 **바닥에서의 높이**예요. 뒷벽은 y = 0, 왼쪽 벽은 x = 0이에요.
   - 도우미 함수: `box`(가구 상자), `plane`(바닥·벽·칠판), `crossed`(화분 잎·전등 빛), `group`(여러 부품 묶기·회전), `label`(이름표)
  - 이미 있는 가구: `chair`, `loungeChair`, `roundTable`, `desk`, `deskLamp`, `panelLight`, `pendant`, `floorLamp`, `bookshelf`, `clock`, `sofa`, `beanbag`, `mobileWhiteboard`, `plant`, `pool`(바닥 빛 번짐)
  - 휴대폰에서도 부드럽게 돌아가도록 방 하나의 부품 수는 너무 많지 않게 해 주세요. 얇은 것(칸막이, 의자 등받이)은 `box` 대신 `plane`을 써요.
- **조명 색**: `space3d.js`의 `LIGHTS`에 프리셋이 있어요.

## 참고
- 소리 크기는 실제 데시벨이 아니라 '느낌'을 보여주는 정도예요. 발표 때 "~70dB 느낌"이라고 말하는 게 정확해요.
- 인터넷이 없으면 글꼴만 기본 글꼴로 바뀌고, 나머지 기능(3D 포함)은 그대로 작동해요.
- 3D 화면 안에서는 손가락으로 끌면 방이 돌아가요. 휴대폰에서 페이지를 스크롤할 때는 3D 화면 바깥을 끌어 주세요.
